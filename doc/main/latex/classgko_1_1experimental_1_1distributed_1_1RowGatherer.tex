class gko\+::experimental\+::distributed\+::\+Row\+Gatherer$<$ Local\+Index\+Type $>$}

The \mbox{\hyperlink{classgko_1_1experimental_1_1distributed_1_1RowGatherer}{distributed\+::\+Row\+Gatherer}} gathers the rows of \mbox{\hyperlink{classgko_1_1experimental_1_1distributed_1_1Vector}{distributed\+::\+Vector}} that are located on other processes. 

Example usage\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{ \{c++\}}
\DoxyCodeLine{\textcolor{keyword}{auto} coll\_comm = std::make\_shared<mpi::neighborhood\_communicator>(comm,}
\DoxyCodeLine{                                                                  imap);}
\DoxyCodeLine{\textcolor{keyword}{auto} rg = \mbox{\hyperlink{classgko_1_1experimental_1_1distributed_1_1RowGatherer_a341d6cc889bf80a42ff9471adbbe5973}{distributed::RowGatherer<int32>::create}}(exec, coll\_comm, imap);}
\DoxyCodeLine{}
\DoxyCodeLine{\textcolor{keyword}{auto} b = \mbox{\hyperlink{classgko_1_1experimental_1_1distributed_1_1Vector_a38e53776a4d12312089c63a55b771df2}{distributed::Vector<double>::create}}(...);}
\DoxyCodeLine{\textcolor{keyword}{auto} x = \mbox{\hyperlink{classgko_1_1matrix_1_1Dense_a04562b9cf07b14ec1ef4865a3fe8e7fa}{matrix::Dense<double>::create}}(...);}
\DoxyCodeLine{}
\DoxyCodeLine{\textcolor{keyword}{auto} req = rg-\/>apply\_async(b, x);}
\DoxyCodeLine{\textcolor{comment}{// users can do some computation that doesn't modify b, or access x}}
\DoxyCodeLine{req.wait();}
\DoxyCodeLine{\textcolor{comment}{// x now contains the gathered rows of b}}
\end{DoxyCode}


\begin{DoxyNote}{Note}
The output vector for the apply\+\_\+async functions {\itshape must} use an executor that is compatible with the M\+PI implementation. In particular, if the M\+PI implementation is not G\+PU aware, then the output vector {\itshape must} use a C\+PU executor. Otherwise, an exception will be thrown.
\end{DoxyNote}
