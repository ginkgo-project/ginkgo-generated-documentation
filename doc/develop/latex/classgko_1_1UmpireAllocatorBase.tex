\doxysubsection{Detailed Description}
Common base of the Umpire-\/backed allocators, which forward to a named allocator in \href{https://github.com/LLNL/Umpire}{\texttt{ Umpire}}\textquotesingle{}s Resource\+Manager. 


\begin{DoxyItemize}
\item Statistics cover everything allocated from the Umpire allocator.
\item Alignment is not checked (application-\/built pools\+: 16 bytes by default).
\item Not serialized by executors; share a pool across threads only if it is thread-\/safe (\mbox{\hyperlink{structgko_1_1umpire__pool__config_a5ad2d9aa3bf0a0d93b059b378ad9044a}{umpire\+\_\+pool\+\_\+config\+::thread\+\_\+safe}}).
\item Each process, hence each M\+PI rank, has its own Resource\+Manager and pools.
\item The accessors are deliberately not noexcept\+: without Umpire they throw \mbox{\hyperlink{classgko_1_1NotCompiled}{Not\+Compiled}}.
\end{DoxyItemize}

\begin{DoxyWarning}{Warning}
Pools are not stream-\/ordered\+: deallocate() frees immediately while Ginkgo\textquotesingle{}s kernels may still use the memory. Call \mbox{\hyperlink{classgko_1_1Executor_a24eeee7648c0f0fd07c9866d07154875}{Executor\+::synchronize()}} before sharing a device pool across streams. 
\end{DoxyWarning}
