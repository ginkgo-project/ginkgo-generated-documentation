\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Value\+Type = default\+\_\+precision$>$\newline
class gko\+::preconditioner\+::\+Nullspace\+Projection$<$ Value\+Type $>$}

\mbox{\hyperlink{classgko_1_1preconditioner_1_1NullspaceProjection}{Nullspace\+Projection}} wraps a preconditioner $ M $ with projections onto the complement of a nullspace, $ z = P M Q r $. 

$ P $ removes the nullspace from the preconditioned vector, which keeps the search directions of a Krylov solver, and thus its solution, orthogonal to the nullspace. The optional $ Q $ removes the left nullspace from the input. If both are the same nullspace, $ P M P $ is symmetric for a symmetric $ M $, which solvers like Minres need on ill-\/conditioned problems or when iterated past convergence.

Iterative solvers that support nullspaces (see \mbox{\hyperlink{structgko_1_1solver_1_1nullspace__traits}{solver\+::nullspace\+\_\+traits}}) wrap their preconditioner in a \mbox{\hyperlink{classgko_1_1preconditioner_1_1NullspaceProjection}{Nullspace\+Projection}} when their {\ttfamily nullspace} parameter is set, unless it already is one removing the nullspace. It can also be used as the preconditioner of any solver directly; then the right-\/hand side and the initial guess need to be projected by the user, see \mbox{\hyperlink{classgko_1_1solver_1_1Nullspace_a52025fcea47fedab07efac0a55a92839}{solver\+::\+Nullspace\+::project}}.

A constant-\/only nullspace is adapted to the size and value type of the system matrix, so the factory can be used for matrices of any size.
