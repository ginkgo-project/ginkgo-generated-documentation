\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Local\+Index\+Type = int32$>$\newline
class gko\+::experimental\+::distributed\+::\+Row\+Scatterer$<$ Local\+Index\+Type $>$}

The \mbox{\hyperlink{classgko_1_1experimental_1_1distributed_1_1RowScatterer}{distributed\+::\+Row\+Scatterer}} scatters local values to their owning processes and accumulates received contributions into a local target. 

This is the transpose of the \mbox{\hyperlink{classgko_1_1experimental_1_1distributed_1_1RowGatherer}{Row\+Gatherer}} operation\+:
\begin{DoxyItemize}
\item \mbox{\hyperlink{classgko_1_1experimental_1_1distributed_1_1RowGatherer}{Row\+Gatherer}} does\+: y\+\_\+local = R $\ast$ x\+\_\+distributed (gather remote values)
\item \mbox{\hyperlink{classgko_1_1experimental_1_1distributed_1_1RowScatterer}{Row\+Scatterer}} does\+: x\+\_\+distributed += R$^\wedge$T $\ast$ y\+\_\+local (scatter and accumulate)
\end{DoxyItemize}

The operation is split into two phases to allow overlapping computation with communication\+:


\begin{DoxyEnumerate}
\item {\ttfamily apply\+\_\+async} packs the send buffer and initiates the M\+PI communication.
\item {\ttfamily wait\+\_\+and\+\_\+accumulate} waits for the communication to complete, then accumulates the received values into the target vector.
\end{DoxyEnumerate}

The scatterer keeps track of the in-\/flight communication, so only one scatter can be active at any given time.

Example usage\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{ \{c++\}}
\DoxyCodeLine{\textcolor{keyword}{auto} rs = \mbox{\hyperlink{classgko_1_1experimental_1_1distributed_1_1RowScatterer_a8e8fb69e14be7fb9439a07d7677272f2}{distributed::RowScatterer<int32>::create\_from\_gatherer}}(exec, rg);}
\DoxyCodeLine{}
\DoxyCodeLine{rs-\/>apply\_async(local\_vals);}
\DoxyCodeLine{\textcolor{comment}{// ... overlap other work while communication is in flight ...}}
\DoxyCodeLine{rs-\/>wait\_and\_accumulate(target);}
\DoxyCodeLine{\textcolor{comment}{// target now has accumulated the scattered values}}
\end{DoxyCode}
