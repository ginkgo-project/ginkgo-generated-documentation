Detailed Description

Common base of the Umpire-backed allocators, which forward to a named allocator in Umpire's ResourceManager.

  • Statistics cover everything allocated from the Umpire allocator.
  • Alignment is not checked (application-built pools: 16 bytes by default).
  • Not serialized by executors; share a pool across threads only if it is thread-safe (umpire_pool_config::thread_safe).
  • Each process, hence each MPI rank, has its own ResourceManager and pools.
  • The accessors are deliberately not noexcept: without Umpire they throw NotCompiled.
Warning
Pools are not stream-ordered: deallocate() frees immediately while Ginkgo's kernels may still use the memory. Call Executor::synchronize() before sharing a device pool across streams.
