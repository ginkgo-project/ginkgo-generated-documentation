Left nullspace $ N(A^H) $ -- the orthogonal complement of $ \mathrm{range}(A) $, given as a Nullspace$<$\+Value\+Type$>$. 

When set, the solver projects the right-\/hand side onto $ \mathrm{range}(A) $, which makes the system consistent, so inconsistent systems are solved in the least-\/squares sense.

The solver then works with the projected right-\/hand side throughout\+: stopping criteria measure the residual of the projected system and loggers receive the projected right-\/hand side. The residual $ b - A x $ of the original system does not drop below the norm of the removed part of $ b $.

For solvers requiring a Hermitian matrix (\mbox{\hyperlink{classgko_1_1solver_1_1Cg}{Cg}}, \mbox{\hyperlink{classgko_1_1solver_1_1Fcg}{Fcg}}, \mbox{\hyperlink{classgko_1_1solver_1_1Minres}{Minres}}), the left and right nullspace coincide, and this defaults to {\ttfamily nullspace}. By default, none. \mbox{\Hypertarget{structgko_1_1solver_1_1enable__preconditioned__iterative__solver__factory__parameters_ae9501b42d279d40332d1ec51051add96}\label{structgko_1_1solver_1_1enable__preconditioned__iterative__solver__factory__parameters_ae9501b42d279d40332d1ec51051add96}}

Right nullspace $ N(A) $ of the (singular) system matrix, given as a Nullspace$<$\+Value\+Type$>$. 

When set, the solver removes the $ N(A) $ component from the initial guess, and wraps its preconditioner in a \mbox{\hyperlink{classgko_1_1preconditioner_1_1NullspaceProjection}{preconditioner\+::\+Nullspace\+Projection}}, which removes it from every preconditioned vector. For a consistent system, i.\+e. a right-\/hand side in $ \mathrm{range}(A) $, this converges to the minimum-\/norm solution. Otherwise, {\ttfamily left\+\_\+nullspace} needs to be set as well\+: Hermitian solvers (\mbox{\hyperlink{classgko_1_1solver_1_1Cg}{Cg}}, \mbox{\hyperlink{classgko_1_1solver_1_1Fcg}{Fcg}}, \mbox{\hyperlink{classgko_1_1solver_1_1Minres}{Minres}}) use the nullspace as left nullspace by default, while \mbox{\hyperlink{classgko_1_1solver_1_1Gmres}{Gmres}} and \mbox{\hyperlink{classgko_1_1solver_1_1Bicgstab}{Bicgstab}} without it stagnate or diverge. The solver\textquotesingle{}s get\+\_\+preconditioner() then returns the wrapper, and get\+\_\+unprojected\+\_\+preconditioner() the wrapped preconditioner.

Supported by the solvers specializing \mbox{\hyperlink{structgko_1_1solver_1_1nullspace__traits}{nullspace\+\_\+traits}} (\mbox{\hyperlink{classgko_1_1solver_1_1Cg}{Cg}}, \mbox{\hyperlink{classgko_1_1solver_1_1Fcg}{Fcg}}, \mbox{\hyperlink{classgko_1_1solver_1_1Minres}{Minres}}, \mbox{\hyperlink{classgko_1_1solver_1_1Gmres}{Gmres}}, \mbox{\hyperlink{classgko_1_1solver_1_1Bicgstab}{Bicgstab}}); other solvers throw \mbox{\hyperlink{classgko_1_1NotSupported}{Not\+Supported}}. A constant-\/only nullspace is adapted to the size and value type of the system matrix, other nullspaces need to match them. For complex value types, the solver\textquotesingle{}s \mbox{\hyperlink{namespacegko_accf17977b47322fff8526d69711e9d7f}{transpose()}} throws \mbox{\hyperlink{classgko_1_1NotSupported}{Not\+Supported}} when a nullspace is set, while conj\+\_\+transpose() is supported.
