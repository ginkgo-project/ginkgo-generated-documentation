Detailed Description

Configuration for a pool created by make_umpire_cpu_pool(), make_umpire_cuda_pool() or make_umpire_hip_pool().

The pool stays registered with Umpire, and keeps its reserved memory, until release() is called or the program exits.

◆ initial_block_size

size_type gko::umpire_pool_config::initial_block_size = size_type{512} << 20

Size in bytes of the pool's first block, requested on first allocation.

Each MPI rank has its own pool, so divide the budget by the number of ranks sharing a GPU or node.

◆ resource

std::string gko::umpire_pool_config::resource = ""

Umpire memory resource to pool over; empty means "HOST" for CPU and "DEVICE" for CUDA/HIP.

May be device-qualified ("DEVICE::1").

A plain "DEVICE" binds to whichever device is current when Umpire first creates it, so a mismatched executor throws. Multi-GPU users should pass "DEVICE::<id>".

◆ thread_safe

bool gko::umpire_pool_config::thread_safe = false

Wrap the pool in Umpire's ThreadSafeAllocator.

Set this if the pool is used from several threads. The unwrapped pool is registered as <name>_pool, and name refers to the wrapper.

◆ tracked

bool gko::umpire_pool_config::tracked = true

Register each allocation in Umpire's tracking registry.

If false, the size/watermark/count getters report 0, and deallocating a foreign pointer is undefined behaviour instead of a reported error.
