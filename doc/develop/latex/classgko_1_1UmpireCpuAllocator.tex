\doxysubsection{Detailed Description}
\mbox{\hyperlink{classgko_1_1Allocator}{Allocator}} using a named Umpire allocator over a host-\/accessible resource. 

\begin{DoxyWarning}{Warning}
Umpire\textquotesingle{}s Resource\+Manager is a function-\/local static and this class holds a non-\/owning handle into it, so an \mbox{\hyperlink{classgko_1_1Executor}{Executor}} using it must not outlive main() (e.\+g. in a global shared\+\_\+ptr). The same holds for \mbox{\hyperlink{classgko_1_1UmpireCudaAllocator}{Umpire\+Cuda\+Allocator}} and \mbox{\hyperlink{classgko_1_1UmpireHipAllocator}{Umpire\+Hip\+Allocator}}. 
\end{DoxyWarning}
