\doxysubsection{Detailed Description}
Configuration for a pool created by \mbox{\hyperlink{namespacegko_a34bec7bb2641d9517e9bb1ee1bef1681}{make\+\_\+umpire\+\_\+cpu\+\_\+pool()}}, \mbox{\hyperlink{namespacegko_a5b338ead111f24a75be0137dc86111e5}{make\+\_\+umpire\+\_\+cuda\+\_\+pool()}} or \mbox{\hyperlink{namespacegko_aadb70ef53c27ababe45b80d6cba01124}{make\+\_\+umpire\+\_\+hip\+\_\+pool()}}. 

The pool stays registered with Umpire, and keeps its reserved memory, until release() is called or the program exits.
