Detailed Description

template<typename LocalIndexType = int32>
class gko::experimental::distributed::RowScatterer< LocalIndexType >

The distributed::RowScatterer scatters local values to their owning processes and accumulates received contributions into a local target.

This is the transpose of the RowGatherer operation:

  • RowGatherer does: y_local = R * x_distributed (gather remote values)
  • RowScatterer does: x_distributed += R^T * y_local (scatter and accumulate)

The operation is split into two phases to allow overlapping computation with communication:

  1. apply_async packs the send buffer and initiates the MPI communication.
  2. wait_and_accumulate waits for the communication to complete, then accumulates the received values into the target vector.

The scatterer keeps track of the in-flight communication, so only one scatter can be active at any given time.

Example usage:

{c++}
auto rs = distributed::RowScatterer<int32>::create_from_gatherer(exec, rg);
rs->apply_async(local_vals);
// ... overlap other work while communication is in flight ...
rs->wait_and_accumulate(target);
// target now has accumulated the scattered values

void gko::experimental::distributed::RowScatterer< LocalIndexType >::apply_async ( ptr_param< const LinOp >  local_values) const

Start scattering local values to their owning ranks.

Packs the local values into a send buffer and initiates the MPI communication. The scatter is finished by calling wait_and_accumulate.

Parameters
local_valuesthe local values to scatter (distributed::Vector). Its local vector must have as many rows as this process sends. It might not be modified before wait_and_accumulate is called.
Exceptions
InvalidStateErrorif a previous scatter has not been finished by wait_and_accumulate.
