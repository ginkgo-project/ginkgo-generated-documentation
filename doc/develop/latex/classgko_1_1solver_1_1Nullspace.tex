\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Value\+Type = default\+\_\+precision$>$\newline
class gko\+::solver\+::\+Nullspace$<$ Value\+Type $>$}

\mbox{\hyperlink{classgko_1_1solver_1_1Nullspace}{Nullspace}} represents the (right or left) nullspace of an operator and {\itshape is} the orthogonal projector $ P = I - V V^H $ onto its complement, where $ V $ is an orthonormal basis of the nullspace. 


\begin{DoxyItemize}
\item The constant vector is handled implicitly by subtracting the mean, so a constant-\/only nullspace works with any vector layout ({\ttfamily \mbox{\hyperlink{classgko_1_1matrix_1_1Dense}{matrix\+::\+Dense}}} or {\ttfamily \mbox{\hyperlink{classgko_1_1experimental_1_1distributed_1_1Vector}{experimental\+::distributed\+::\+Vector}}} with any partition).
\item An explicit basis is copied and orthonormalized once at creation time (twice-\/iterated Gram-\/\+Schmidt, also against the constant if it is part of the nullspace). Columns that are numerically linearly dependent (relative norm below $ \sqrt{\epsilon} $ after orthogonalization) are dropped; \mbox{\hyperlink{classgko_1_1solver_1_1Nullspace_a0a40f0105e4915471bd304c839309a49}{get\+\_\+dimension()}} reports the remaining dimension.
\item \mbox{\hyperlink{classgko_1_1solver_1_1Nullspace_a52025fcea47fedab07efac0a55a92839}{project()}} removes the nullspace components of all columns of its input $ X $ at once\+: the coefficients $ C = V^H X $ and the column means are computed in a single pass (and, for distributed vectors, a single all-\/reduce), followed by $ X \leftarrow X - V C $.
\end{DoxyItemize}

The typical use is as the {\ttfamily nullspace} / {\ttfamily left\+\_\+nullspace} parameter of an iterative solver, see \mbox{\hyperlink{structgko_1_1solver_1_1enable__preconditioned__iterative__solver__factory__parameters}{enable\+\_\+preconditioned\+\_\+iterative\+\_\+solver\+\_\+factory\+\_\+parameters}}.

The object is immutable after creation apart from internal scratch buffers. Solvers and \mbox{\hyperlink{classgko_1_1preconditioner_1_1NullspaceProjection}{preconditioner\+::\+Nullspace\+Projection}} work on their own copy, which shares the basis, so the same object can be passed to any number of factories. Like other Ginkgo Lin\+Ops with internal caches, a single instance must not be applied concurrently from multiple threads.

Creates a \mbox{\hyperlink{classgko_1_1solver_1_1Nullspace}{Nullspace}} consisting only of the constant vector (e.\+g. 

a pure-\/\+Neumann Poisson problem). The constant is never materialized, so the result can project vectors of any type and distribution.

Solvers adapt a constant-\/only nullspace to the size and value type of their system matrix, so the same object can be used in solver factories that are generated for matrices of different sizes (e.\+g. on the levels of a multigrid hierarchy) or precisions. Without a size, \mbox{\hyperlink{classgko_1_1solver_1_1Nullspace_a52025fcea47fedab07efac0a55a92839}{project()}} accepts vectors of any size; the size is only needed to use the \mbox{\hyperlink{classgko_1_1solver_1_1Nullspace}{Nullspace}} as a \mbox{\hyperlink{classgko_1_1LinOp}{Lin\+Op}}.
