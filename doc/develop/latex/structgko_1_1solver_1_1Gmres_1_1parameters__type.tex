Restart ratio. 

A cycle ends once the residual has fallen to this fraction of its value at the start of the cycle, that is, once $ \|r_i - A d_i\| \leq \text{restart\_ratio} \cdot \|r_i\| $ holds for every right-\/hand side still running, with $r_i$ the residual at the start of the cycle and $d_i$ the correction built so far. This bounds the normwise backward error of the correction, which is what makes the restarted method analyzable as iterative refinement. A cycle cut short by krylov\+\_\+dim carries no such bound.

It is a per-\/cycle reduction, not a convergence tolerance, so useful values are far larger than a stopping criterion\textquotesingle{}s. It must lie in \mbox{[}0, 1) and must exceed the reduction a krylov\+\_\+dim-\/step cycle achieves, or it never fires\+: use 1e-\/3 to 1e-\/1 when a cycle gains orders of magnitude, and around 0.\+9 when it gains only a few percent.

Zero, the default, disables the criterion.

For the criterion and its analysis, see sec. 4.\+2 of \href{https://doi.org/10.1093/imanum/draf049}{\texttt{ A Modular Framework for the Backward Error Analysis of G\+M\+R\+ES}}.
