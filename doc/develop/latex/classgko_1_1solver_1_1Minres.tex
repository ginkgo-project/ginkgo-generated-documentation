\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Value\+Type = default\+\_\+precision$>$\newline
class gko\+::solver\+::\+Minres$<$ Value\+Type $>$}

\mbox{\hyperlink{classgko_1_1solver_1_1Minres}{Minres}} is an iterative type Krylov subspace method, which is suitable for indefinite and full-\/rank symmetric/hermitian operators. 

It is a specialization of the \mbox{\hyperlink{classgko_1_1solver_1_1Gmres}{Gmres}} method for symmetric/hermitian operators, and can be computed using short recurrences, similar to the CG method.

The implementation in Ginkgo makes use of the merged kernel to make the best use of data locality. The inner operations in one iteration of \mbox{\hyperlink{classgko_1_1solver_1_1Minres}{Minres}} are merged into 2 separate steps.

For more details see Anne Grennbaum\textquotesingle{}s \textquotesingle{}Iterative Methods for Solving Linear Systems\textquotesingle{} (D\+OI\+: 10.\+1137/1.9781611970937), and Sou-\/\+Cheng (Terrya) Choi\textquotesingle{}s \textquotesingle{}I\+T\+E\+R\+A\+T\+I\+VE M\+E\+T\+H\+O\+DS F\+OR S\+I\+N\+G\+U\+L\+AR L\+I\+N\+E\+AR E\+Q\+U\+A\+T\+I\+O\+NS A\+ND L\+E\+A\+S\+T-\/\+S\+Q\+U\+A\+R\+ES P\+R\+O\+B\+L\+E\+MS\textquotesingle{}.

\begin{DoxyNote}{Note}
\+: The \mbox{\hyperlink{classgko_1_1solver_1_1Minres}{Minres}} solver only reports an approximation of the residual norm directly to the stopping criteria. Neither the actual residual, nor the actual residual norm are reported. Thus, to get the minimal overhead, the \mbox{\hyperlink{classgko_1_1stop_1_1ImplicitResidualNorm}{gko\+::stop\+::\+Implicit\+Residual\+Norm}} criteria should be used. The \mbox{\hyperlink{classgko_1_1stop_1_1ResidualNorm}{gko\+::stop\+::\+Residual\+Norm}} criteria will require an additional matrix-\/vector product and global reduction.
\end{DoxyNote}
